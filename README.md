## ✨ Key Features

- **🌐 Multi-Language Support (TR / EN):** Dynamic language switching with complete i18n parity across all sections, descriptions, typewriter effects, and modals.
- **🎨 Modern Dark UI & Glassmorphism:** Clean aesthetic, neon accent gradients, smooth animations, and interactive hover effects.
- **🎮 Interactive Project Showcase:** Spotlight section with video gameplay showcases (e.g. *Spark Champions: 3D Arena Survival*), categorical filters, and full modal previews.
- **⏳ Timeline Experience & Education:** Structured career milestones highlighting university education, internships, and engineering experience.
- **📊 Skills Matrix:** Visual progress bars and skill badges covering Data Analytics, Business Intelligence, SQL & Databases, Web Development, and Machine Learning.
- **📜 Verified Credentials:** Integrated section for certificates and professional references.
- **📱 Fully Responsive:** Adaptive mobile-first design with smooth scrolling and responsive navigation menu.
- **⚡ SEO & Performance:** Structured data (JSON-LD Schema), Open Graph tags, canonical URLs, and Google Analytics 4 integration.

## 💻 Getting Started Locally

To run this website on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ercanpolatt/ercanpolatt.github.io.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd ercanpolatt.github.io
   ```

3. **Open the project:**
   - Double-click `index.html` to launch it in your default browser, or
   - Start a local server:
     ```bash
     # Python 3
     python -m http.server 3000
     ```
